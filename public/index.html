Gerador de massa de dados

Escolha o tipo de dado, defina a quantidade e receba JSON ou CSV prontos para seus testes.

O que gerar

Pessoas e empresas

Endereços

Vendas e pagamentos

Formato

Em “Endereço”, qualquer idioma diferente de pt-BR retorna o endereço internacional.

Opções avançadas

A mesma seed gera sempre os mesmos dados. Útil para reproduzir um cenário de teste.

Separe por vírgula e use ponto para campos aninhados. Se “somente estes campos” estiver preenchido, a remoção é ignorada.

Atalho: Ctrl + Enter

Documentação da API

      
    


    

      
A interface usa a mesma API pública. Tudo o que você gera aqui também pode ser pedido por script.


      
Endpoint

      
GET /generate?segment=pf&count=10&format=json&locale=pt-BR


      
Parâmetros

      

        

          
ParâmetroPadrãoDescrição

          
            
segmentpfTipo de dado: pf, pj, contato, cliente, endereco, endereco_internacional (ou intl), produto, pedido, transacao, cartao.

            
count1Quantidade de registros, de 1 a 100.

            
formatjsonjson ou csv. No CSV o separador é ; e objetos aninhados vão como JSON na célula.

            
localept-BRIdioma dos dados (en, es, fr, de…). Um idioma não suportado retorna erro 400.

            
seednenhumNúmero inteiro. A mesma seed e os mesmos parâmetros geram os mesmos dados, incluindo os IDs.

            
includenenhumMantém só os campos listados, com ponto para aninhados: nome,endereco.cep.

            
excludenenhumRemove os campos listados. É ignorado quando include é usado.

          
        

      


      
Exemplos

      
curl "http://localhost:9292/generate?segment=cliente&count=5"

curl "http://localhost:9292/generate?segment=pedido&count=3&seed=42"

curl "http://localhost:9292/generate?segment=pf&count=50&format=csv" -o pessoas.csv

curl "http://localhost:9292/generate?segment=pf&include=nome,email,endereco.cep"

Erros

      
Parâmetros inválidos retornam 400 com uma mensagem em JSON, por exemplo {"error": "Formato inválido. Use json ou csv."}. Nenhum dado é gerado nesse caso.
